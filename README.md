# Blackout Heist

Lojë kompetitive asimetrike 1v1 në Java: një hajdut kundër sistemit të sigurisë, me presion kohe dhe nivele.

## Ekipi
- Glauk Rraci – QA & Project
- Yllka Dedinca – Game Design, Architecture & Interaction
- Melos Klaiqi – Logic, Algorithm & Software

## Ideja e shkurtër
Hajduti duhet të vjedhë një objekt dhe të dalë para se të mbarojë koha. Mbrojtësi kontrollon rojet, kamerat dhe dyert. Pas çdo raundi rolet ndërrohen. Nivelet rrisin vështirësinë.

## Qëllimi i projektit
Ta shndërrojmë algoritmet A*, line-of-sight dhe gjenerimin e hartave në një lojë të luajtshme dhe konkurruese, duke praktikuar Java, GitHub dhe punën në ekip.

## Algoritmet kryesore
- A* për lëvizjen e rojeve
- Line-of-sight (raycasting) për konin e shikimit
- Gjenerim proceduralist i hartave me BFS

## Çfarë nuk përfshihet
Multiplayer në rrjet, grafikë 3D, histori/narrativë, tingull i personalizuar, ruajtje në server.
